#  Getting Started

This article describes how to get started with PresentationKit.

PresentationKit makes it easy to perform value-based ``Navigation`` and value-based alert, sheet, modal, and toast ``Presentation``. 

## Presentation

The ``Presentation`` class is the foundation of PresentationKit. It holds an optional item that can be presented and dismissed, and is used with all presentation modifiers in the library.

See <doc:Presentation-Article> for more information.

## Navigation

The ``Navigation`` class makes it easy to perform value-based navigation with a navigation stack.

See <doc:Navigation-Article> for more information.

## Alerts

PresentationKit makes it easy to present alerts and automatically handle errors thrown during async operations.

See <doc:Alerts-Article> for more information.

## Sheets

PresentationKit makes it easy to present sheets, with additional utilities for animated size changes and size-to-fit behavior.

See <doc:Sheets-Article> for more information.

## Full Screen Covers

PresentationKit makes it easy to present full screen covers on all non-macOS platforms.

See <doc:Full-Screen-Covers-Article> for more information.

## Toasts

PresentationKit makes it easy to present toasts that slide in from a screen edge and auto-dismiss after a configurable duration.

See <doc:Toasts-Article> for more information.
